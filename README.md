# Manasvita Sharma — professional portfolio

Live website: https://manasvitaa.github.io/

The homepage covers strategy, analytics, commercial insights, healthcare experience, education, and personal interests.

## Update the site

Edit the root `index.html`, `styles.css`, `visual.css`, `journey.css`, and `script.js` files. Images and the favicon are in `assets/`. The site uses standard HTML, CSS, and JavaScript with no external packages.

GitHub Pages publishes the `main` branch root. `.nojekyll` keeps this a plain static site. The older `portfolio/` folder is preserved.

The public website links to LinkedIn. A downloadable résumé is not included.
